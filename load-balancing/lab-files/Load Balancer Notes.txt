IP addresses

remember 5 ips always reserved in subnet /256 example 254 addresses


Azure reserves 5 IP addresses in every subnet: the first four and the last address.
For a /24 subnet, there are 256 total addresses and 251 usable addresses.
Exam rule

Remember it this way:

Azure subnet usable IPs = total subnet IPs minus 5

So:

Subnet	Total IPs	Usable in Azure
/24	256	251
/27	32	27
/28	16	11
/29	8	3

This matters on AZ-104 when a question asks whether a subnet is large enough for VMs, Application Gateway, VPN Gateway, private endpoints, or scale sets.

In Azure, every subnet loses 5 IP addresses because Azure reserves them for networking functions. Microsoft documents this as the first four addresses and the last address in each subnet.

Example: /24 subnet

For this subnet:

10.1.0.0/24

There are 256 total addresses:

10.1.0.0 through 10.1.0.255

But Azure reserves these 5:

Address	Reserved for
10.1.0.0	Network address
10.1.0.1	Azure default gateway
10.1.0.2	Azure DNS mapping
10.1.0.3	Azure DNS mapping
10.1.0.255	Broadcast address

So the usable range is:

10.1.0.4 through 10.1.0.254
